# Аналитикам

Раздел содержит вспомогательные материалы для аналитиков, которые раскрывают специальные возможности Stormbpmn: работа с таблицей бизнес-процессов (фильтрация, сортировка, поиск, настраиваемые колонки и вкладки с наборами фильтров, шаблоны для команды, экспорт в .xlsx), симуляция токена для проверки работоспособности диаграмм на задачах с прикреплёнными событиями, а также генерация регламентов бизнес-процессов и ролей по настраиваемым шаблонам на SpEL с выгрузкой в DOCX.
