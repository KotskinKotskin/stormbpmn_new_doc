Создание и настройка опросов

Опрос — это инструмент для сбора обратной связи от пользователей, исполнителей процессов или внешних респондентов. Опросы позволяют измерить зрелость процессов, выявить узкие места, оценить качество выполнения задач или собрать мнения по конкретным BPMN-моделям.

В Stormbpmn опросы можно создавать как независимые сущности, так и привязывать их к конкретным бизнес-процессам или диаграммам. Это помогает структурировать сбор данных и анализировать результаты в контексте конкретных объектов архитектуры.

Создание опроса

Перейдите в раздел опросов. Для создания нового опроса нажмите кнопку Создать опрос:

Откроется экран настройки опроса, который состоит из двух основных этапов: выбора привязки и выбора шаблона (или создания с нуля).

Выбор типа привязки

Сначала нужно определить, к чему будет привязан опрос. Доступны три варианта:

  1. Независимый — универсальный опрос без привязки к конкретной модели или процессу. Подходит для внешней рассылки, сбора общей обратной связи от широкой аудитории или анкетирования, не связанного с конкретным элементом реестра.
  2. Модель — опрос привязан к конкретной BPMN-модели. Респонденты могут запускать опрос со страницы диаграммы. Ответы помогают улучшать логику конкретного процесса, описанного на схеме.
  3. Процесс — опрос привязан к карточке бизнес-процесса из реестра. Удобно для сбора обратной связи по сквозному процессу, который может состоять из нескольких моделей или этапов.

Выберите нужный тип привязки, кликнув по соответствующей карточке:

Если вы выбрали привязку к Модели или Процессу, появится поле для выбора конкретного объекта:

  • Для модели: выберите диаграмму из списка доступных.
  • Для процесса: выберите карточку процесса из реестра.

Выбор шаблона или создание с нуля

После выбора привязки перейдите к разделу Шаблон. Система предлагает готовые шаблоны опросов для типовых задач:

  • Зрелость процесса — 5 вопросов для определения уровня зрелости.
  • Эффективность процесса — 5 вопросов для измерения эффективности.
  • Качество выполнения — 5 вопросов для проверки соответствия стандартам.
  • Узкие места и риски — 5 вопросов для выявления ключевых проблем.
  • Управление изменениями — 5 вопросов для оценки готовности к изменениям.
  • Роли и ответственности — 5 вопросов для проверки распределения обязанностей.
  • Документация процесса — 5 вопросов для оценки качества документации.
  • Автоматизация процесса — 5 вопросов для определения уровня автоматизации.
  • Взаимодействие участников — 5 вопросов для оценки коммуникации.

Также доступен вариант Новый опрос, который позволяет создать опрос с нуля, без использования готовых вопросов.

Чтобы посмотреть вопросы в шаблоне перед его выбором, нажмите кнопку Посмотреть вопросы рядом с нужным шаблоном.

Настройка опроса

После выбора привязки и шаблона (или создания с нуля) откроется редактор опроса. В нем вы можете настроить название, приветствие, вопросы и финальное сообщение.

Название опроса

Введите понятное название опроса в поле Название опроса. Это название будет отображаться в списке опросов и поможет вам быстро найти нужный опрос в будущем.

Приветствие

В разделе Приветствие создайте текст, который увидят пользователи в начале опроса. Здесь можно описать цель опроса, инструкции для респондентов или контекст, необходимый для правильного заполнения.

Добавление вопросов

В разделе Вопросы добавьте вопросы, которые будут включены в опрос. Если вы выбрали шаблон, вопросы уже будут добавлены. Если вы создавали опрос с нуля, нажмите Добавить вопрос, чтобы создать новый вопрос.

Для каждого вопроса можно настроить:

  • Текст вопроса — введите текст в поле Вопрос.
  • Описание вопроса (необязательно) — добавьте пояснение или контекст в поле Описание.
  • Обязательность — включите тумблер Обязательный вопрос, если респондент не сможет пропустить этот вопрос.

Чтобы изменить порядок вопросов, перетащите их мышью. Также доступны следующие действия:

  • Дублировать вопрос — создает копию текущего вопроса.
  • Добавить вопрос ниже — вставляет новый вопрос сразу после текущего.

Валидация

Опрос должен содержать хотя бы один вопрос. Система не позволит сохранить опрос без вопросов.

Финальное сообщение

В разделе Финальное сообщение настройте текст, который участники увидят после прохождения опроса. Здесь можно поблагодарить респондента, указать, куда обращаться с вопросами, или сообщить о следующих шагах.

Сохранение опроса

После настройки всех элементов нажмите кнопку Сохранить. Опрос будет создан и появится в списке доступных опросов. По умолчанию опрос находится в черновике и не доступен для прохождения, пока вы не опубликуете его.

Доступ к опросу

Доступом к опросу управляет его автор или администратор команды. Если вы видите сообщение «Опрос доступен только для просмотра», запросите у автора права на редактирование.

Дальнейшие действия

После создания опроса вы можете:

  • Опубликовать его для сбора ответов.
  • Настроить доступ для респондентов.
  • Просмотреть результаты в разделе Результаты опросов.
  • Протестировать прохождение опроса в режиме респондента (Прохождение опроса).
