Работа с редактором UML

В Stormbpmn есть встроенный и удобный UML-редактор, поддерживающий версионирование, работу с базовыми шаблонами, комментарии, экспорт UML как PNG или SVG. Также есть возможность создавать и изменять UML-диаграмму с помощью AI-ассистента.

Создание UML-диаграммы с нуля

  1. В главном меню Stormbpmn кликните по кнопке на верхней панели управления справа от кнопки Модели и выберите PlantUML из выпадающего списка:

  2. Выберите наиболее удобный для вас вариант создания UML-диаграммы:

    Вне зависимости от выбора способа создания UML-диаграммы — будет открыто окно редактора UML-диаграмм и будет создана диаграмма под названием Черновик в разделе Все модели.

  3. По умолчанию при загрузке редактора UML-диаграмм автоматически выбирается стартовый шаблон Класс:

    Шаблон можно сменить, кликнув на кнопку Создать по шаблону и выбрав один из следующих шаблонов:

    • Класс — классовая диаграмма. Подходит для описания структуры системы: классов, их атрибутов, методов и отношений между ними.
    • Последовательность — диаграмма последовательности (sequence-диаграмма). Показывает порядок взаимодействия объектов и участников процесса во времени.
    • Прецедент — диаграмма вариантов использования (use case). Описывает функциональность системы с точки зрения внешних пользователей (акторов) и сценариев её работы.
    • Активность — логическая диаграмма (activity-диаграмма). Используется для моделирования бизнес-логики, алгоритмов и последовательности действий при решении задачи.
    • Компонент — диаграмма компонентов. Показывает высокоуровневую структуру системы, её модули (компоненты) и зависимости между ними.

  4. После внесения изменений в UML-диаграмму её можно сохранить, кликнув на кнопку Сохранить как версию на верхней панели инструментов:

  5. Измените название диаграммы (по желанию), добавьте теги и укажите папку, куда будет сохранена диаграмма (опционально, по умолчанию диаграмма будет сохранена в раздел Все модели):

  6. Нажмите кнопку Сохранить как версию.

Управление предпросмотром UML-диаграммы

По умолчанию окно предпросмотра UML-диаграммы горизонтальное и находится снизу. Это не всегда удобно, особенно когда диаграмма большая. Окно предпросмотра можно сделать вертикальным и расположить его справа от редактора кода UML-диаграммы. Для этого кликните по кнопке Переключить на вертикальное разделение на верхней панели управления:

Также диаграмму можно приближать и отдалять с помощью сочетания зажатой клавиши Ctrl + колёсика мышки или жестов на тачпаде (обычно это два пальца, движущихся вверх или вниз). Вернуться быстро к дефолтному размеру диаграммы можно с помощью кнопки Сбросить масштаб:

Совместная работа над диаграммой

По умолчанию диаграмма публична и доступна для просмотра и редактирования (если выданы права) участникам команды. Чтобы поделиться диаграммой с участниками команды или приглашёнными людьми, кликните по кнопке Поделиться на верхней панели инструментов и выберите нужный вам способ приглашения к совместной работе:

  • Отправка приглашения людям с доступом — укажите e-mail адреса людей, у которых есть доступы к командному Stormbpmn, задайте уровень прав (просмотр или редактирование диаграммы) и нажмите кнопку Предоставить доступ:

  • Сделать диаграмму публичной — создать публичную ссылку, чтобы любой человек в интернете смог посмотреть процесс по ссылке и подать прошение на участие в совместной разработке. Скопируйте ссылку кликом по кнопке Копировать ссылку и завершите процесс публикации ссылки в интернете нажатием на кнопку Предоставить доступ:

Также для более эффективной совместной работы или просто для фиксации важных идей можно воспользоваться комментариями. Секция Комментарии находится в правой боковой панели:

Выгрузить диаграмму как изображение

UML-диаграмму можно выгрузить как изображение в SVG- и PNG-формате:

  1. Кликните по на верхней панели управления и из выпадающего списка выберите :

  2. Выберите нужный вам формат для выгрузки диаграммы как изображения:

    • svg-формат отлично подходит для презентаций, отчётов и других промо-материалов и интернет-публикаций, так как он легко масштабируется без потери качества.
    • png-формат хорошо подойдёт для публикаций или отчётов небольших размеров, так как png — это растровый формат рисунка и он теряет качество при масштабировании.
