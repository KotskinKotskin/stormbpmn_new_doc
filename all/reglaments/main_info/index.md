# Регламенты: общие сведения

➡️ (_templates/warnings/plan.md)
➡️ (_templates/reglaments/main_info.md)

В {{ product_name }} регламенты генерируются в формате DOCX. Система автоматически заполняет их данными на основе DOCX-шаблонов, которые подготавливают аналитики или другие ответственные члены команды.

Доступно три типа регламентов: 

- Процессов.
- Ролей.
- Элементов архитектуры (ЭА).

Шаблоны пишутся с использованием языка разметки [SpEL](https://docs.spring.io/spring-framework/reference/core/expressions.html) (Spring Expression Language). Структура шаблона не регламентирована и составляется на усмотрение ответственных лиц. Для отправной точки в создании собственных шаблонов регламентов можно воспользоваться нашими готовыми шаблонами:

- [Базовый шаблон](https://disk.yandex.ru/i/A_r2pR_ma0dLPg) для быстрого старта.
- [Краткий шаблон](https://disk.yandex.ru/i/A_r2pR_ma0dLPg) регламента.
- [Расширенный шаблон](https://disk.yandex.ru/i/SvPWDpMdyEpvZQ) регламента. [Пример](https://disk.yandex.ru/i/kv62j46wSRE_Nw) выгрузки регламента по этому шаблону с раскрытием источников информации.
- [4 варианта](https://disk.yandex.ru/i/lSHwv4s1ZzqJ9A) табличного описания шагов процесса.
