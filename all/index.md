# Всем

Раздел содержит вспомогательные материалы по функциям и возможностям Stormbpmn, которые используют все аудитории: создание и изменение диаграмм с помощью AI-помощника, отправка процессов на согласование, работа с редактором UML, управление видимостью диаграмм, работа со слоями видимости (оверлеями), горячие клавиши редактора, рейтинг качества процесса с автоматической проверкой ошибок и общие сведения о регламентах.
