# Работа с переменными

Переменные в документации {{ product_name }} занимают одно из ключевых мест в её технической составляющей. Они обеспечивают однообразие использования информации, сокращают количество ошибок и унифицируют работу с документацией. Переменные используются для обозначения любых активных элементов интерфейсов: кнопок, переключателей, активных полей — всего, у чего есть инфографика.

Переменные распределены по классам и типам и содержатся в `.yml` файлах в директории `vars`. Файлы с переменными подключаются в главный сводный файл `vars.yml`, который находится в корне документации.

Указываются переменные в тексте и ссылках с помощью двойных фигурных скобок: `{{` и `}}`. Сама же ссылка на значение переменной может содержать произвольное количество вложенной иерархии, обозначающейся через точку. Например: переменная `folders.folder_up` будет заменена на значение <i class="pi pi-arrow-up"></i> **Поднять папку на самый верхний уровень**.

## Добавление переменных

У каждой переменной есть своё место в файлах переменных, которые повторяют структуру интерфейса {{ product_name }}. Название `.yml` файла в директории `vars` указывает на интерфейс {{ product_name }}, а имя самой переменной — на конкретный активный элемент интерфейса {{ product_name }}.

Перед добавлением переменной сначала убедитесь в том, что такой переменной ещё нет в `.yml`-файлах. Если нужной вам переменной нет и вы хотите её добавить, например, это переменная, обозначающая кнопку с инфографикой в интерфейсе {{ product_name }} — откройте сначала devtools (кнопка `F12`), выберите инструмент **Выделение** и кликните на нужную вам кнопку:

![]({{ media.screenshots.devtools }}/devtools_select.png)

Далее обратите внимание на выделенную часть HTML-кода, в ней должен содержаться `i` или `span` элемент с классом `pi`. Например, в нашем случае — `pi pi-user`:

![]({{ media.screenshots.devtools }}/devtools_select_class.png)

Теперь нужно скопировать два селектора класса: `pi pi-user` и вставить их `main.yml` или в `vars.yml`:

```yml
acc:
  main_button: '<i class="pi pi-user"></i>'
```

## Переменные путей

Особое место среди иерархии переменных занимают переменные путей скриншотов. Они находятся в файле `media.yml` и нужны для свободного изменения структуры материалов документации. Переменные путей в `media.yml` имеют следующую иерархию и структуру:

- Вначале файла идут переменные, указывающие на пути к директориям, где располагаются скриншоты:

    ```yml
    media:
    screenshots:
        var_name: path_to_media_folder
    ```

- Далее идут переменные, указывающие на сам скриншот:

    ```yml
    actions:
        proc_versioning: proc_versioning
    ```

Так полный путь до скриншота состоит из двух переменных: `{{` `path to folder` `}}` и `{{` `screenshot name` `}}`. Такое разделение помогает структурировать переменные внутри директории `media`.
