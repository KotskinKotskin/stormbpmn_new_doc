# Структура документации

В корневой директории документации находятся следующие файлы:

- `nav.yaml` — оглавление документации. После добавления новых страниц материалов их необходимо внести в оглавление. Пути указываются от корня документации. Если в названии материала присутствует двоеточие — применяются одинарные кавычки.  
- `vars.yaml` — сборный файл с переменными документации. Почитать как работать с переменными можно [тут](../vars/index.md).
- `index.md` — домашняя страница документации.
- `umda.yml` — конфигурационный файл системы препроцессенга MarkDown-файлов UMDA.

Структура документации по состаянию на 26.07.2026:

```txt
.
├── _templates # Шаблоны уведомлений
├── admins     # Материалы для администраторов команд
├── all        # Материалы для всех
├── analytics  # Материалы для аналитиков
├── approvals  # Материалы для ревьюнеров и согласующих
├── architects # Материалы для системных архитекторов
├── beginners  # Материалы для начинающих
├── media      # Хранилище скриншотов
├── main       # Материалы для разделов FAQ, быстрый старт, видеозаписи, о документации 
├── vars       # Техническая секция документации. Поддиректория содержит `.yml`-файлы с переменными, которые входят в состав vars.yaml 
```

Статьи размещены в поддиректориях в файлах `index.md`. Текст статей пишется в Markdown-формате. Применение HTML-разметки не запрещено.
