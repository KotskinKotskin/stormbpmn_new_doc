<h3 id="roles"> Роли </h3>

<div class="admonition-container" markdown="1">

⚠️ "Ограничения прав и подписки"
    Создавать роли может только **администратор команды**. Роли — это часть платной подписки **TEAM** или **Enterprise**.

⚠️ "Поведение Ролей"
    Роли — это объекты команды, а не пользователя. При выходе из команды или переходе в другую команду роли удаляются с диаграмм, и их оверлеи на диаграммах пропадают (восстановление невозможно).

</div>

ℹ️🔽 "Общие сведения о ролях"

    **Роль** — это исполнитель конкретной задачи, а не должность. Одна роль может подходить для нескольких должностей: например, "Инициатором закупки товаров" может быть офис-менеджер, бухгалтер или завхоз. Наоборот, одна должность (как директор) может выполнять несколько ролей — от административных до юридических или бухгалтерских.

    Роли переиспользуемы и предпочтительнее дорожек для описания исполнителей.

ℹ️🔽 "Создание ролей"
    
    Роль можно создать в разделе {{ section_team.buttons.team_switcher }} {{ universal.right_arrow }}  {{ section_team.layouts.roles }}, нажав на кнопку {{ role.buttons.create_role }}:

    ![create_role]({{ media.screenshots.assignees }}/create_role.png)

    Также роль можно создать прямо в редакторе диаграмм при работе с активными элементами диаграммы, например: {{ bpmn.end_event }} или {{ bpmn.call_activity }}. Для этого выберите активный элемент, нажмите кнопку {{ process_editor.right_toolbar.buttons.archetecture }} в правом меню и нажмите кнопку {{ universal.plus }} **Создать и установить новую роль** справа от поля **Роль**:

    ![create_new_role_from_edit_process]({{ media.screenshots.diagram }}/{{ media.actions.diagram_roles }}/create_new_role_from_edit_process.png)

    Оба пути создания ролей приводят к одному и тому же модальному окну **Создание роли**, в котором можно задать:

    - **Название роли** (обязательное поле) — поддерживается кириллица, латиница, специальные символы (автоэкранируются).
    - **Тип роли** (обязательное поле) — один из трёх типов роли: *Человек*, *Система*, *Не указано*.
    - **Стоимость в час** (опциональное поле) — целочисленное значение (автоматическое разделение разрядов пробелом).

    ![role_options]({{ media.screenshots.assignees }}/role_options.png)

    После создания роли она появится в разделе {{ section_team.layouts.roles }}, где также отразятся: **Должности** и **Процессы**, в которых используется роль:

    ![roles_list]({{ media.screenshots.assignees }}/roles_list.png)

ℹ️🔽 "Редактирование ролей"
    
    Роли располагаются в разделе {{ section_team.layouts.roles }}. Там же их можно редактировать, нажав на кнопку {{ role.buttons.edit_role }}. После нажатия на кнопку откроется модальное окно **Создание роли**, в котором можно задать:

    - **Название роли** (обязательное поле) — поддерживается кириллица, латиница, специальные символы (автоэкранируются).
    - **Тип роли** (обязательное поле) — один из трёх вариантов типов роли: *Человек*, *Система*, *Не указано*.
    - **Стоимость в час** (опциональное поле) — целочисленное значение (автоматическое разделение разрядов пробелом).

    ![role_options]({{ media.screenshots.assignees }}/role_options.png)

    **Должность** присваивается **Роли** в разделе {{ org_structure.name }} {{ universal.right_arrow }}  {{ org_structure.scheme }}, а **Роль** задействуется в **Процессе** с помощью **Редактора диаграмм**. 
    
    См. **FAQ по Stormbpmn: Создание ролей**.

ℹ️🔽 "Привязка ролей к задачам"

    Роли к задачам привязываются в редакторе диаграмм:

    1. Перейдите в редактор диаграмм, выберите задачу, к которой хотите привязать роль, и в правом боковом меню выберите вкладку {{ process_editor.right_toolbar.buttons.archetecture }}:

        ![role_add_task]({{ media.screenshots.diagram }}/{{ media.actions.diagram_roles }}/role_add_task.png)

    2. Кликните по выпадающему списку **Роль** и выберите роль, которую хотите привязать к задаче:

        ![apply_role_to_task]({{ media.screenshots.diagram }}/{{ media.actions.diagram_roles }}/apply_role_to_task.png)

    Если нужной вам роли в списке ещё нет — создайте её, кликнув на кнопку {{ universal.plus }} **Создать и установить новую роль**. См. FAQ: Роли/создание ролей.

ℹ️🔽 "Удаление роли с задач"

    Удалить роль с задач или отвязать задачи от роли можно двумя путями:

    - Отвязать роль от задачи через редактор диаграмм.
    - Просмотреть список задач, назначенных на роль, в разделе {{ section_team.layouts.roles }}, перейти по ссылке и отвязать роль от задачи через редактор диаграмм.


    **Отвязка роли от задачи через редактор диаграмм**:

    1. Перейдите в редактор диаграмм, выберите задачу, с которой хотите отвязать роль, и в правом боковом меню выберите вкладку {{ process_editor.right_toolbar.buttons.archetecture }}:

        ![drop_down_task_from_role]({{ media.screenshots.diagram }}/{{ media.actions.diagram_roles }}/drop_down_task_from_role.png)

    2. Кликните на **X** справа от названия назначенной роли у задачи, чтобы отвязать роль:

        ![delete_task_from_role]({{ media.screenshots.diagram }}/{{ media.actions.diagram_roles }}/delete_task_from_role.png)

    **Отвязка роли от задачи через раздел {{ section_team.layouts.roles }}**:

    1. Перейдите в раздел {{ section_team.buttons.team_switcher }} {{ universal.right_arrow }} {{ section_team.layouts.roles }}:

        ![delete_task_from_role_section_roles]({{ media.screenshots.assignees }}/delete_task_from_role_section_roles.png)

    2. В разделе будет отражён список ролей с соответствующими им должностями и процессами, в которых эти роли задействованы:

        ![tasks_list_roles_review]({{ media.screenshots.assignees }}/tasks_list_roles_review.png)

    3. Кликните по названию процесса или задачи, чтобы перейти в процесс, где к выбранной роли привязаны задачи, и в редакторе диаграмм удалить привязку или назначение.
