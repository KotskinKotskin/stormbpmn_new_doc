ℹ️🔽 "Переход с базового тарифа на тарифы **Team** и **Business**"

    1. Войдите в аккаунт и в рабочее пространство {{ product_name }}.
    2. Кликните по кнопке {{ account_dropdown_menu.icon }} в верхней панели управления справа.
    3. Из выпадающего списка выберите пункт {{ account_dropdown_menu.upgrade_plan }}:

        ![upgrade_plan]({{ media.screenshots.profile }}/{{ media.actions.profile_plan }}/upgrade_plan.png)
    
    4. Выберите интересующий вас тариф:

        ![choose_plan]({{ media.screenshots.profile }}/{{ media.actions.profile_plan }}/choose_plan.png)

    Кликните на свернутую внизу экрана подсказку **Сравнение тарифов** для получения списка возможностей каждого тарифа и их наглядного сравнения.
