<h3 id="dict">Справочник</h3>

ℹ️🔽 "Что такое {{ team.bp_reg.dict }}"

    Справочник — это набор заранее определенных пользовательских значений. Справочники используются для организации логически схожей информации. Проще всего представить справочник в виде выпадающего списка, в котором можно выбрать одну или несколько записей для отображения.

    Поля справочника могут быть заполнены любыми типами данных (строки, целые числа, числа с плавающей точкой, логические (булевы) значения и прочие), которые будут преобразованы в строковые данные.

    Справочники **не поддерживают** выполнение математических или логических операций над значениями.

ℹ️🔽 "Создание справочника"

    Справочники могут использоваться как наборы пользовательских параметров процессов. Например, можно задать категорию процесса или его статус. Чтобы создать справочник:

    1. Перейдите в раздел {{ team.icon }} {{ universal.right_arrow }} {{ team.bp_reg.dict }}.
    1. Нажмите кнопку {{ team.bp_reg.create_dict }}.
    1. В открывшемся модальном окне **Создание справочника** заполните следующие поля:

        - **Название справочника** — ёмкое и понятное название. Учтите, что справочник будет представлен в виде выпадающего списка — название должно отражать суть его элементов.
        - **Примечание** — описание справочника; может содержать пояснения к элементам, их свойства или отличия.
        - **Значения справочника** — элементы справочника, которые будут доступны для выбора при работе со справочником. Количество элементов не ограничено, тип данных — любой.
    1. Нажмите кнопку **Создать**.

    Созданный справочник автоматически будет отражён в разделе {{ team.bp_reg.dict }}:

    ![dict_list]({{ media.screenshots.directories }}/dict_list.png)

ℹ️🔽 "Использование справочника как параметра процесса"

    1. Перейдите в раздел {{ team.icon }} {{ universal.right_arrow }} {{ team.bp_reg.bp_tree }}.
    1. Выберите бизнес-процесс, к которому хотите добавить справочник, перейдите во вкладку {{ bp_tree.options }} карточки бизнес-процесса и нажмите {{ universal.plus }} **Добавить параметр**:

        ![add_option]({{ media.screenshots.registry }}/{{ media.actions.registry_add_options }}/add_option.png)
    
    1. В открывшемся модальном окне **Добавление параметра** нажмите {{ universal.plus }}.
    1. На шаге **Создание параметра** выберите **Тип параметра**: **Одиночный выбор** для представления справочника в виде выпадающего списка с возможностью выбора одной записи или **Мульти-выбор** для выбора нескольких значений справочника.
    1. После выбора типа параметра в форме появятся новые поля:

        - **Название** — укажите название параметра. Оно будет отображаться в {{ bp_tree.options }}.
        - **Подсказка для ввода** — пояснение для выбора значений параметра.
        - **Справочник** — выбор справочника для привязки к параметру карточки процесса.
        - **Примечание** — дополнительное описание параметра.
    1. Нажмите кнопку **Сохранить**, затем **Добавить**.
    1. После добавления параметра к процессу он будет отражён в секции {{ bp_tree.options }}:

        ![add_new_option_final]({{ media.screenshots.registry }}/{{ media.actions.registry_add_options }}/add_new_option_final.png)
    1. Активируйте поле **Значение не установлено** и выберите нужное значение из выпадающего списка.

    После первой привязки справочника к процессу и назначения ему имени как параметру, справочник можно добавлять к другим процессам через кнопку {{ universal.plus }} **Добавить параметр**.


ℹ️🔽 "Удаление справочника"

    ⚠️ "Привязка к полям процесса"
        Справочник, привязанный к полям процесса, невозможно удалить. Сначала нужно отвязать справочник в карточке процесса в секции {{ bp_tree.options }}.

    Для удаления справочника нажмите на {{ universal.delete }} справа от столбца **Обновлено**:

    ![dict_delete]({{ media.screenshots.directories }}/dict_delete.png)
