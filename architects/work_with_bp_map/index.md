# Работа с картой бизнес-процессов

{{ bp_reg.map }} — визуальное представление архитектуры бизнес-процессов ({{ bp_reg.tree }}) в виде иерархической диаграммы:

![bp_reg_map_def]({{ media.screenshots.map }}/bp_reg_map_def.png)

{{ bp_reg.map }} отражает:

- Иерархию бизнес-процессов.
- Ключевые метрики.
- Статусы бизнес-процессов.
- Владельца бизнес-процесса.

{{ bp_reg.map }} позволяет не просто просматривать верхнеуровнево общую картину всех бизнес-процессов в {{ bp_reg.tree }} (по умолчанию отражаются все процессы), а фокусироваться на конкретном процессе с помощью инструмента {{ map.buttons.focus }}:

![bp_reg_map_focus_btn.png]({{ media.screenshots.map }}/bp_reg_map_focus_btn.png)

Сфокусироваться можно на любом уровне вложенности процесса. Уровень вложенности будет отражаться сверху в мини-панели навигации по процессу:

![bp_reg_map_focus_result_deep.png]({{ media.screenshots.map }}/bp_reg_map_focus_result_deep.png)

Фокусировка — отличный инструмент для того, чтобы рассмотреть детали работы бизнес-процесса. Если нужно что-то изменить в бизнес-процессе -- есть возможность просмотра и редактирования параметров бизнес-процесса.

Для открытия параметров бизнес-процесса кликните по его названию:

![bp_reg_map_show_proc_options]({{ media.screenshots.map }}/bp_reg_map_show_proc_options.png)

Откроется модальное окно отображения параметров бизнес-процесса, которые можно редактировать прямо здесь или кликнуть по ссылке **перейти к процессу** и перейти в {{ bp_reg.tree }}:

![bp_reg_map_forward_to_bp_tree]({{ media.screenshots.map }}/bp_reg_map_forward_to_bp_tree.png)

{{ bp_reg.map }} — это не просто иное представление {{ bp_reg.tree }}, а самостоятельный инструмент анализа бизнес-процессов, позволяющий не только просмотреть параметры определенного бизнес-процесса, но и удобно их отредактировать.
