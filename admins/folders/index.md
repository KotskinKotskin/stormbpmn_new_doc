# Структурированное хранение бизнес-процессов

Структурированное хранение материалов — это основа эффективности командной работы, ведь когда все в команде знают, что где лежит, работа идёт значительно быстрее.

В {{ product_name }} реестр бизнес-процессов логически отделен от моделей бизнес-процессов и у этих сущностей разные представления и разные структуры хранения.

Модели бизнес-процессов хранятся в общедоступном командном пространстве и их хранение может быть организовано по-разному. Для структурирования хранения бизнес-процессов используют два механизма организации структурированного хранения: {{ universal.folder }} **Папки** и **Теги**.

{{ universal.folder }} **Папки** и **Теги** предназначены для организации хранения диаграмм бизнес-процессов и их структурирования по общему признаку, например, признаком может быть принадлежность к направлению деятельности, продукту, функции, подразделению компании, владельцу процесса и т.д. 

{{ universal.folder }} **Папки** и **Теги** помогают группировать связанные диаграммы процессов под "общим флагом". Это облегчает их поиск, управление ими и особенно полезно при работе с большим количеством схем и сложной связанностью между ними.

## Создание папок и структуры для хранения бизнес-процессов

1. Перейдите в {{ section_team.buttons.team_switcher }} {{ universal.right_arrow }} {{ bs_models.bs_m }} {{ universal.right_arrow }} {{ bs_models.folders }}:

    ![folders_expore](/{{ media.screenshots.folder }}/{{ media.actions.folder_creating }}/folders_expore.png)

1. Создайте папку с помощью кнопки {{ universal.plus }} **Создать новую папку** в верхней левой части секции навигации по структуре директорий:

    ![folders_create_folder](/{{ media.screenshots.folder }}/{{ media.actions.folder_creating }}/folders_create_folder.png)

1. Введите название папки и нажмите кнопку **Сохранить**:

    ![folders_create_folder_set_name](/{{ media.screenshots.folder }}/{{ media.actions.folder_creating }}/folders_create_folder_set_name.png)

Если нужно создать вложенную папку — перейдите в родительскую папку и кликните по кнопке {{ universal.plus }} **Создать дочернюю папку** на панели управления папками в правой секции окна управления папками:

![folders_create_subfolder](/{{ media.screenshots.folder }}/{{ media.actions.folder_creating }}/folders_create_subfolder.png)

Над папками можно выполнять следующие действия:

- **Создать папку/вложенную папку** — кнопки {{ universal.plus }} **Создать папку** и {{ universal.plus }} **Создать дочернюю папку**.
- **Изменить название папки/вложенной папки** — кнопка {{ universal.edit_2 }} на панели управления папками в правой секции окна управления папками.
- **Поднять папку на самый верхний уровень** — кнопка {{ folders.folder_up }} на панели управления папками в правой секции окна управления папками.
- **Удалить папку/вложенную папку** — кнопка {{ universal.delete }} на панели управления папками в правой секции окна управления папками.

Для свободного перемещения папки по структуре её нужно удерживать мышкой и перетянуть в нужное вам место структуры папок.

## Распределение бизнес-процессов по структуре хранения 

1. Откройте существующую диаграмму бизнес-процесса или создайте новую диаграмму в редакторе диаграмм.
1. Кликните по кнопке {{ process_editor.upper_toolbar.buttons.save_as_version }} на верхней панели управления:
    ![editor_save_as_version](/{{ media.screenshots.diagram }}/{{ media.actions.folder_creating }}/editor_save_as_version.png)

1. В модальном окне **Сохранение модели**:

    - Задайте **Название** диаграммы.
    - Добавьте **Теги** при необходимости.
    - Выберите папку, куда нужно сохранить диаграмму. Вложенную структуру папок можно развернуть, кликнув по выпадающему меню **Название папки**.
    - Нажмите кнопку **Сохранить**.

После сохранения диаграммы соответствующий ей бизнес-процесс появится в указанной папке:

![folders_save_process](/{{ media.screenshots.folder }}/{{ media.actions.folder_creating }}/folders_save_process.png)
